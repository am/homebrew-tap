# am's Homebrew tap

```sh
brew install am/tap/mcprj
```

| Formula | What it is |
| ------- | ---------- |
| `mcprj` | Read and write Elektron Model:Cycles project files (`.mcprj`). Source and docs: [am/repreprep/tools/mcprj](https://github.com/am/repreprep/tree/main/tools/mcprj). Needs Node, which Homebrew installs with it. |

Update with `brew upgrade mcprj`.
